# Expression library asset policy

The active expression-library illustrations were created specifically for the
Betshuva project. They are not scraped or downloaded photographs, clips, GIFs,
celebrity images, stage performances, or copyrighted fictional characters.

Family figures are fictional, generic illustrations generated from a prompt
that expressly excludes real people, public figures, singers, storytellers,
brands, logos, and existing characters. Animated GIFs are created locally from
project-original illustrations using deterministic transforms and sparkles.

This provenance record reduces third-party copyright risk but is not a legal
warranty. New assets must follow the same policy and receive visual review
before being added to the public catalog.
