# Removed face model weights

The previously copied face detection, landmark, age, and gender model weights
were not loaded by the production server or Flutter application. They were
removed on 2026-08-21 because the project did not contain an explicit licence
or permission covering distribution of those binary weights.

Do not add or restore model weights until all of the following are recorded:

1. The exact source URL and revision from which each file was downloaded.
2. The licence text or written permission explicitly covering the weights.
3. Any attribution, notice, redistribution, and commercial-use requirements.
4. Any separate restrictions applying to the training datasets.

If that evidence cannot be obtained, replace the weights with models whose
commercial-use and redistribution terms are explicit.
