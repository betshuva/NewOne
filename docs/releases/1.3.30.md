# Release 1.3.30+250 — September 22, 2026

Native Android camera recordings returned by CameraX with a `.temp` suffix are saved as MP4 with `video/mp4` metadata before playback and upload. This fixes the unsupported-file response in private and group conversations. Manual stop and the automatic 30-second recording limit are covered by regression tests. The release preserves the existing native image clipboard, save/share and scan-report changes in the application snapshot.
