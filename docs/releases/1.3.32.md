# Release 1.3.32+252 - September 23, 2026

New camera captures and voice recordings use descriptive names containing
`betshuva`, the media type, local date and time to hundredths of a second, and
the creator's user ID prefixed with uppercase `ID`. For example:
`betshuva-video-2026-09-23_14-07-36-42-ID-12345.mp4`.
The timestamp is captured when recording starts or a photo is taken. Existing
files and gallery imports retain their names, and photo/video extensions
continue to reflect the actual format. Same-time collisions receive a suffix.

New voice recordings are converted to real MP3 on the server before hashing,
storage and moderation. The returned MP3 filename is used throughout private
and group message flows. Conversion has bounded input size, duration, queue
wait, concurrency and subprocess resources. Imported audio is unchanged.
The release also includes the existing Google web sign-in button changes and
their required source files and dependency declaration.
