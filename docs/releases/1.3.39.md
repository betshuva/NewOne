# Release 1.3.39+259 — October 1, 2026

Publishes a 2 GB service allowance per user, with warnings at 80%, 90% and 95%.
The media library offers old-file cleanup with explicit confirmation. Connecting
personal Google Drive routes new files and queues existing approved files there;
company/local copies are retired only after a fresh download, decryption and
integrity check. The release includes central Drive storage and Gmail admin tools.

Also packages the recent attachment upload batches, resumable uploads, clipboard
handling, filename editing, upload diagnostics and local video-sampling changes.
The batch-limit tests now cover both 100 accepted files and the current behavior
of rejecting the entire 101-file selection without starting uploads.
