# Release 1.3.37+257 — September 28, 2026

Audio uploads accept files up to 150 MiB without a media-duration limit. Audio-only
WebM files are classified by their tracks, and client-side size rejections are
recorded in the system audit. Reusing a voice-message widget now switches to the
correct recording even when an earlier download completes late.

Audio playback supports seeking, an exact-time dialog and saved progress for
each authenticated user. Web video playback supports the same progress and seek
workflow. Native Android video resume is not part of this change. Server-side
access checks and progress revisions isolate users and reject stale writes.

This release also packages the current chat, search, media-history and audit
interface updates. The full audit icon font and its license are included in the
Flutter web source assets so subsequent deployments preserve them.
