# Release 1.3.38+258 — September 29, 2026

Packages the recent media playback, upload-state and security fixes. Audio streams
without downloading the entire recording first and displays the filename. Upload
progress avoids duplicate pending cards, and attachment/camera overlays prevent
click-through playback on web video. The extra web-video time-jump button is removed;
native video controls and saved per-user progress remain available.

The backend release restricts static file delivery, hardens reset/OTP/session handling,
updates vulnerable dependencies and escapes untrusted admin content. The exposed
Firebase service key was moved outside the public directory. **Cloud key rotation
remains outstanding** because IAM management was unavailable; see the
[security review](../security/security-review-2026-09-29.md).
