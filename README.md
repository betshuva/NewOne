פריט חדש. תיקיות התמונות הישנות נשמרות להצגת הודעות קודמות ולתאימות.

דורשת עדכון חד־פעמי; אחרי עדכון זה, תוספות לספריות יופיעו גם בה ללא בנייה נוספת.
